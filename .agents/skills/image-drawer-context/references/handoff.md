# 別エージェントへの短い引き継ぎ

目的は、長い会話やログを再読せず、次の一件に必要な根拠へ進めるようにすることです。

記録は作業に対応する場所へ置いてください。外部への記載が許可されていればIssue・PRの説明、ローカル作業ならGit管理外の `reports/agent-handoff.md` などを使います。新しい投稿や共有の許可をこの手順自体が与えるわけではありません。

```text
目的 / 完了条件:
対象 / 触らない範囲:
基準コミット / 作業ブランチ / 未コミット変更:
変更したこと:
確認したこと: コマンド・結果・対象環境
未確認 / 制約:
次の一件:
根拠: 対象ファイル・定義名・必要ならIssue/PR
```

後続はGit状態と関係する元ファイルを照合してから再開してください。記録だけで成功・承認・マージ済みと判断しません。
生ログや会話全体を貼らず、失敗時は原因を判断できる箇所とログの保存先を残します。
同じ作業の古い引き継ぎは要点を置き換え、進捗の追記で長くしないでください。繰り返し必要になった検索先だけを[作業別の入口](routing.md)へ移します。
