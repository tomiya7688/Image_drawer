# はじめて読む Image Drawer 設計ガイド

## まず何を作るの？

Image Drawerは**txt2img（文章から画像を作るAI）**。ただし、完成画像を一回の処理で生成するのではなく、**人間の絵師が絵を描くように、AIが自分で筆を選び、線を引き、色を重ね、必要に応じて修正する**ことが中心です。

```text
ユーザー：「青い服の少女を描いて」
    ↓  入力は文章だけ。参照画像は不要
白紙のキャンバス
    ↓
AIが道具・色・レイヤーを選択
    ↓
AIが下書き・線画・着色・修正の筆跡を実行
    ↓  毎回、更新後のキャンバスを見て次の行動を決める
完成画像＋描画した操作の全履歴
```

最終的な画像を作ることも目的ですが、**「AIが描き方自体を学習したか」**がさらに重要です。画像のパーツを組み合わせるだけではImage Drawerの目標を達成しません。

## 決まっていること／まだ決まっていないこと

| 内容 | 現時点の扱い |
| --- | --- |
| イラスト全般を対象とする | **方針確定** |
| ユーザーは文章だけで生成できる | **方針確定** |
| AIが実際の制作行動を学ぶ | **方針確定** |
| 固定256色。ブラシと色は別々に選ぶ | **方針確定** |
| 定番のブラシをプリセットから選ぶ | **方式確定**。初期12種の中身は実装前レビュー対象 |
| サイズ・不透明度・筆圧は固定段階を選ぶ | **方式確定**。19/11/11段階は初期採用値 |
| 一筆全体の筆圧パターンも学習する | **方式確定**。5パターン（うちその他1）を初期採用 |
| 人間の生の筆圧・座標を消さない | **方針確定** |
| 高精度ブラシの画素計算・水彩の質感 | **まだ詳細設計・実装が必要** |
| 人間の実演からの学習精度 | **未実測**。「高精度が保証された」とは言わない |

## AIが筆を描くまでの手順

1. **ブラシを選ぶ。** 例：Gペン。鉛筆、厚塗り、エアブラシなどもプリセットから選べる。
2. **サイズを選ぶ。** 例：5px。全ての小数値を予測するのではなく19段階から一つ。
3. **不透明度を選ぶ。** 例：80%。5%、10%、20%…100%の11段階。
4. **色を選ぶ。** 固定の256色から番号で選ぶ。色とブラシは別の行動。
5. **筆を動かす。** 座標の軌跡と各点の筆圧を予測し、筆圧は11段階を使用する。
6. **筆圧の流れも予測する。** 一定、次第に強く、次第に弱く、両端が弱い、その他の5パターン。ただしパターンだけで筆跡を固定しない。
7. **結果を観察して繰り返す。** 描き直す・別の色を使う・別レイヤーを作る・完成させる、などもAIが選ぶ。

例えば「5px」を選んだときも、筆圧で実際の太さは変わります。**固定段階なのはモデルが選択する制御値**であって、絵が5px単位の粗い線だけになるわけではありません。座標はサブピクセル精度を維持します。

## なぜ生の操作を残すの？

人間の筆圧が73%だった場合、学習用の筆圧levelは70%に丸めます。しかし**本当に入力された73%も保存**します。

将来「筆圧は10%刻みより5%刻みが良い」と分かったときに、元の実測値から作り直せるためです。元の測定値と学習用の段階値を混同しません。

## 実装者に伝える大切な区別

- **旧`raster-v1`**は、整数画素・単一ブラシでも同じ操作で同じ画素になるかを調べる**再生テスト用**の基準です。
- **新`brush-v2-core12`**は、イラスト全般を描くための**高精度描画器用の設計案**です。まだ全ブラシの数値計算・画素ゴールデンテストは未完成です。
- **段階表のJSON**は数値とIDの唯一の正本です。[brush_control_levels_v2.json](brush_control_levels_v2.json)。**12プリセットのJSON**は[brush_presets_v2.json](brush_presets_v2.json)。人が読む説明と矛盾したら、実装前に文書とJSONを揃えます。
- **ブラシのパターンを作ること≠制作行動を学習したこと**。人間の実演を教師に、モデル自身が白紙から絵を完成させるまでが最終目標です。

**現在は設計PRのレビュー段階です。** CIが通っていても描画器・実演収集器・学習モデルが完成したことにはなりません。
