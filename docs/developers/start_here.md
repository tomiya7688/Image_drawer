# はじめて読む Image Drawer

## 1. Image Drawerはどんなソフト？

**文章だけでイラストを生成するtxt2img**。ただし画像を一度に変換するのではなく、**AIがブラシで実際に描く**。

### 学習するとき

> 学習に必要な外部入力は画像のみとする。
> ユーザーおよび開発者は、画像以外の補助データを用意する必要はない。
> タグ・説明文・プロンプトは、必要に応じてシステム側で自動抽出する。

**内部ではテキストも使いますが、入力してもらうわけではありません。** 画像から抽出した文章を学習用プロンプトにして、AIに「何を描くか」を伝えます。

たとえば「赤いリンゴの画像」を登録すると、

1. ソフトが画像から必要な**タグ・説明文を自動生成**する。抽出器は利用者が切り替えられる。
2. システムが学習用プロンプトを組み立て、**TextEncoderが文章の意味を表す特徴へ変換**する。描画AIにはそれと自分のキャンバスだけを渡す。**元画像は渡さない**。
3. AIが白紙に**ラフ→下書き→本描き→基本色→陰影・仕上げ→修正・確認→完成**の順に描く。
4. **評価する別の仕組みだけ**が、元画像と描いた画像を比較して点数を付ける。
5. その点数を使い、AIの描画行動を選ぶモデルを更新する。もう一度描いて改善したか試す。

**人間が描いた筆跡やペンタブの測定値を用意する必要はない**。完成画像から人間の筆の動きを逆算することもしない。**AI自身が描いて学ぶ。**

### 画像を生成するとき

```text
ユーザー：「青い服の少女を描いて」
        ↓
AIが白紙から決められた工程の順番で描く
        ↓
完成イラスト ＋ 描画履歴（再生可能）
```

生成時に元画像・参考画像を渡す必要はない。

## 2. 描く順番は固定

| 順番 | 何をする？ |
| --- | --- |
| 1. ラフ | 構図・大まかな形を描く |
| 2. 下書き | 位置・比率・形を整える |
| 3. 本描き | 本番の線や面を描く |
| 4. 基本色 | 主な色を置く |
| 5. 陰影・仕上げ | 影・光・質感・ハイライトを付ける |
| 6. 修正・確認 | 必要な所を直し、修正不要なら確認する |

**7工程すべてを順番に通る。スキップと逆戻りはできない。** モノクロ・フラット作品で色や陰影を描く必要がなければ、その工程へ入って理由を記録し、確認してから次へ進む。修正不要なら無理に筆跡を追加しない。各工程で何をどう描くかはAI自身が学ぶ。

[詳しい工程の仕様](fixed_drawing_workflow_v2.md)。実装者向けには[工程の実行・失敗時のルール](stage_controller_contract_v2.md)、学習担当向けには[各工程で何を評価するか](stage_reward_v2.md)も用意しています。

## 3. 道具はどう選ぶ？

**色は共通の256色**から選ぶ。ブラシは色とは別に**12種類の定番プリセット**から選ぶ。

| 設定 | 代表値 |
| --- | --- |
| サイズ | 1, 2, 3, 5, 10, 50, 100pxなどの**19段階** |
| 不透明度 | 5%、10%、20%…100%の**11段階** |
| 筆圧 | 0%、10%…100%の**11段階** |
| 筆圧の変化 | 一定、強くなる、弱くなる、両端が弱い、その他 |

これによりAIは、細かな数値を無限に予測する代わりに**決まった候補から選ぶ**。座標は曲線が滑らかになるようサブピクセル精度で持つ。

[ブラシの一覧](brush_presets_v2.md) ／ [サイズ・不透明度・筆圧の段階表](brush_control_levels_v2.md)。

## 5. 今はどこまでできている？

**決まっている**：画像だけの学習入力、抽出器の切替方式、固定の制作工程、固定256色、初期ブラシ12種、サイズ/不透明度/筆圧の段階表。

**まだできていない**：動作する画像学習Trainer、Tag/Caption抽出器の選定と実装、高精度ブラシ12種のRenderer、固定工程Controller、イラストの画質が実際に上がるという検証。

旧`raster-v1`のゴールデンテストは、古いActionの画素を一致させるために残す。**設計やCIが通っただけでは、画像だけでイラストを描けるモデルが完成したとは言わない。**
