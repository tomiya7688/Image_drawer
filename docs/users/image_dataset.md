> **対象読者:** 学習用の画像を登録して使う人
>
> **目的:** 完成画像のディレクトリを、学習に使えるDatasetとして登録する。

# 画像だけのDatasetを登録する

学習に必要な素材は**完成画像だけ**です。タグと説明文は、選んだ抽出器がソフトウェアで自動生成します。手描きの実演、筆圧のログ、タグ表を用意する必要はありません。

## 準備

Pillowが必要です。リポジトリのルートで次のコマンドを実行してください。

```bash
python -m pip install -e ".[dataset]"
```

## 登録する

```bash
image-drawer-dataset register <画像のディレクトリ> --dataset <Datasetの保存先>
```

- 対象は `.png`、`.jpg`、`.jpeg`、`.webp`、`.bmp`、`.tif`、`.tiff` です。元の画像は変更しません。
- 完全に同じ画像は1件だけ登録されます。わずかな明るさの変更や再保存など、同じ作品の派生とみなせる画像は同じグループにまとめられ、train・validation・testへの分割はグループ単位で決まります。
- アニメーション、壊れたファイル、サイズ上限を超えるファイルは登録されず、結果の `errors` に理由が出ます。終了コードは1です。
- 画像は、向きと色空間をそろえたRGBのPNGとして保存されます。透明な部分は白背景に合成されます。解像度は変わりません。

## 抽出器を選ぶ

```bash
image-drawer-dataset extractors
image-drawer-dataset register <画像のディレクトリ> --dataset <保存先> --tagger <タグ抽出器のid> --captioner <説明文抽出器のid>
```

タグ抽出器と説明文抽出器は別々に選べます。既定の `color-layout-tags` と `color-layout-caption` は、モデルを使わず、画素から主な色と向きだけを取り出す基本の抽出器です。精度の高い抽出器ではありません。タグ抽出を使いたくない場合は、`--tagger none` を指定してください。この場合、学習用の文章は説明文だけから作られます。抽出器を変えて再登録すると、画像ごとに再抽出され、Datasetは別の学習条件として扱われます。同じ設定で再登録すると、キャッシュを使います。

文章を作れなかった画像（学習用の文章が空）は、登録は残りますが、学習の対象から外れます。`manifest.json` の `quality_issues` に理由が残ります。文章やタグを手で用意する必要はありません。

## 内容を確認する

```bash
image-drawer-dataset show --dataset <保存先>
```

画像の件数、splitごとの件数、Datasetのハッシュ、選んだ抽出器が表示されます。`manifest.json` を手で書き換えると、読み込み時にハッシュの不一致でエラーになります。

## 制限

- 高性能なタグ付けモデルは組み込まれていません。必要な場合は、同じ抽出器の契約でPythonから登録してください([開発者向け文書](../developers/image_dataset.md))。
